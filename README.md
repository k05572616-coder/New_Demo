 # Inventory Management System
 This project is a simple yet powerful Inventory Management System designed to Techelp track, manage, and organize products efficiently. It supports adding, updating,
 and deleting items, monitoring stock levels, and generating reports for better decision-making. 

 # Features
 Track all the inventory items
 Manage inventory and allocation
 Get stock status information
 PDF generation
 Stock Graphs
 Dashboard

 # Tech Stack 
 >Frontend: HTML, CSS, JS, Bootstrap
 >Backend: PHP
 >Database: MYSQL
